# fast-laya-compaction Claude Code mod

This plugin uses Claude Code function hooks to replace a compaction with the
original messages, minus the tool calls and tool results a local Laya model
judged no longer needed. `hooks/fast-jev.ts` (name kept from upstream) is a
thin adapter: it reads the plugin options, hands `session.compact` transcripts
to the `fast-laya-compaction` library in `src/` (the plugin folder is the
repository root, so the hook imports it directly) and maps the result back
onto session messages. User and assistant text is never touched. For every
tool call outside the pinned first and newest messages, Laya gets two
questions: whether the call should stay and whether its full output should
stay. An item is kept when Laya's probability reaches `keepThreshold`; a
dropped result is truncated to its first `truncateHeadChars` characters plus a
one-line note, and a dropped call disappears with its result.

Laya's context window is small (1024 tokens native), so in the default
`stateMode: local` each call gets its own state, fitted to `maxStateTokens`:
the goal, the call with the head of its output, and one line per later tool
call plus later messages abridged — later calls touching the same path or
command, and later user prompts, are budgeted first. One request per call,
`concurrency` in flight at once. `stateMode: whole` sends upstream's shared
whole-conversation state instead and only makes sense for a large-context
judge. Token counts are estimated without a tokenizer.

The mod is an early-access Claude Code function-hook module. The checked-in
type reference was generated by Claude Code **2.1.274**. Start the Laya server
and enable the function hooks surface before installing or loading it:

```sh
pip install laya
python server/laya_server.py        # keeps running; 127.0.0.1:8756

export CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1
claude plugin marketplace add scaredos/fast-laya-compaction
claude plugin install fast-laya-compaction@fast-laya-compaction
```

For local development:

```sh
CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 claude --plugin-dir .
```

## Configuration

The plugin declares these `userConfig` values in
`.claude-plugin/plugin.json`:

| Option | Default |
| --- | ---: |
| `baseUrl` | `http://127.0.0.1:8756/predict` |
| `stateMode` | `local` |
| `concurrency` | `8` |
| `rules` | `true` |
| `keepThreshold` | `0.5` |
| `preserveRecentMessages` | `6` |
| `compactAtPercent` | `60` |
| `minReductionRatio` | `0.25` |
| `maxStateTokens` | `500` |
| `maxRequestTokens` | `620` |
| `truncateHeadChars` | `300` |
| `model` | `router` |

No API key is needed. The server address can be set as the `baseUrl` plugin
option or through `LAYA_URL` in the Claude Code environment; `model` picks the
Laya checkpoint (`router` auto-selects by language, or `english`,
`multilingual`, `typed-decisions`).

Every option except `baseUrl`, `compactAtPercent`, `minReductionRatio` and
`model` is passed straight to the library; see the root README for what they
do. If the Laya server is unreachable or fails, the response is malformed, the
history cannot be fitted into the state budget (`whole` mode), or the estimated
reduction is below `minReductionRatio`, the hook logs a fallback and delegates
to Claude Code's built-in compaction. The outcome is shown as a toast and
logged with the reduction, per-reason counts, state size and request count; a
per-call `decisions:` line with both probabilities is logged for diagnosis.
The `turn.complete` hook requests compaction when `context.percent` reaches
`compactAtPercent`, with an in-flight guard.

## Scope and caveat

Function hooks are early access and may change between Claude Code releases.
This mod uses the generated declarations from 2.1.274 in
`types/claude-code.d.ts`; regenerate and review that file after a
Claude Code upgrade.
